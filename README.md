# 🚀 Projeto Evolução Full Stack

Este repositório representa um desafio pessoal: **programar, aprender e evoluir constantemente**.

A proposta é começar com um projeto simples e melhorá-lo ao longo do tempo, aplicando cada novo conhecimento adquirido durante meus estudos de desenvolvimento web.

Conforme eu avançar em tecnologias como HTML, CSS, JavaScript, React, Node.js, bancos de dados e outras ferramentas, este projeto também será atualizado.

A expectativa é que ele comece pequeno e, gradualmente, transforme-se em um **sistema Full Stack completo**.

---

## 💡 Ideia do projeto

O projeto será um sistema de **compra e venda de produtos**, combinando funcionalidades de:

* Loja virtual;
* Dashboard administrativo;
* Gerenciamento de produtos;
* Gerenciamento de usuários;
* Autenticação;
* Controle de pedidos e vendas.

O sistema poderá possuir dois tipos principais de usuários:

### Cliente

O cliente poderá visualizar produtos, pesquisar itens, adicionar produtos ao carrinho e realizar compras.

### Vendedor ou administrador

O vendedor poderá cadastrar produtos, editar informações, acompanhar vendas e visualizar dados por meio de um dashboard.

---

## 🎯 Objetivo principal

O principal objetivo deste projeto não é apenas construir uma aplicação, mas acompanhar minha evolução até me tornar um desenvolvedor Full Stack.

Cada funcionalidade deverá representar algum conceito estudado e colocado em prática.

Ao longo do desenvolvimento, pretendo praticar:

## 📌 Regras do desafio

1. O projeto deverá evoluir conforme meus estudos avançarem.
2. Sempre que eu aprender algo relevante, devo tentar aplicá-lo no projeto.
3. Não é necessário programar uma grande funcionalidade todos os dias.
4. Pequenas melhorias também contam como evolução.
5. Antes de adicionar uma tecnologia, devo entender por que ela será utilizada.
6. O código antigo poderá ser refatorado sempre que eu aprender uma maneira melhor de desenvolvê-lo.
7. As funcionalidades deverão ser adicionadas gradualmente.
8. Bugs e dificuldades encontradas deverão ser registrados.
9. Cada evolução importante deverá possuir um commit claro.
10. O objetivo não é terminar rapidamente, mas acompanhar meu crescimento como desenvolvedor.

## 📖 Definições do projeto

### Projeto evolutivo

Este é um projeto que será desenvolvido continuamente. Sua estrutura, tecnologias e funcionalidades poderão mudar conforme novos conhecimentos forem adquiridos.

### Refatoração

Refatorar significa melhorar a organização e a qualidade do código sem necessariamente alterar o funcionamento da aplicação.

### Front-end

Parte visual do sistema com a qual o usuário interage, incluindo páginas, botões, formulários, produtos, menus e dashboards.

### Back-end

Parte responsável pelas regras de negócio, autenticação, processamento de dados, comunicação com o banco de dados e criação de APIs.

### API

Meio utilizado para permitir a comunicação entre o front-end, o back-end e outros serviços.

### Autenticação

Processo utilizado para verificar quem é o usuário, normalmente por meio de e-mail e senha.

### Autorização

Processo que define quais funcionalidades cada usuário poderá acessar.

### Responsividade

Capacidade da aplicação de se adaptar corretamente a celulares, tablets e computadores.
